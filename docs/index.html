The music player that tells you the truth about your files

Mugig plays your music bit-perfect and gapless, and checks every file while it’s at it: is that “lossless” FLAC really lossless, is it intact, and how loud is it?

Audio quality check

Is that FLAC really lossless?

A FLAC made from an MP3 is still an MP3 underneath. Mugig looks at the audio itself, not the file name, and tells you what it finds in plain words.

  • IntegrityDecodes the whole file and compares it with the MD5 checksum stored in the FLAC. Finds WAV files that were cut short.
  • Lossy sourceSpots files converted from MP3 or AAC by the encoder’s frequency cut-off and the gaps lossy encoders leave in the spectrum.
  • Fake hi-resFinds 24-bit files padded from 16 bits, and 96 kHz files upsampled from CD quality.
  • Loudness and peaksIntegrated loudness (ITU-R BS.1770-4, in LUFS), true peak, the DR dynamic range figure, and clipping.
  • SpectrogramWith a colour legend, an adjustable range of levels, and the cut-off marked, so you can see for yourself.

A verdict for every song

Check one song, or Check All Songs in the background. Results are saved, so each file is only checked once, until it changes. The Quality column sorts like any other.

Lossless Hi-Res Lossless? Lossy Damaged

Honest about how sure it is

Mugig says “very likely” or “probably”, never a made-up percentage. Measured on a real library of 833 files:

93%of MP3s decoded to 16-bit files were caught
1.6%of genuine lossless files were flagged by mistake

A Lossless? verdict is a reason to look at the spectrogram, not proof.

Listening

Your music, exactly as it was recorded

Nothing touches the sound unless you ask it to. When you do, the tools are the ones serious listeners reach for.

Bit-perfect

The output opens at each song’s own sample rate, and on macOS the device itself switches to it, then switches back when you quit. Now Playing tells you when the sound reaches your DAC unconverted.

Gapless

Songs at the same sample rate run straight into each other, so live albums, classical works and DJ mixes play as recorded. The silence MP3 encoders add is trimmed off.

Exclusive access macOS

While a song plays, Mugig has your DAC to itself: no system alerts or other apps mixed in, and nothing changing its sample rate behind your back.

Controls → Exclusive Access

Ten-band parametric EQ

Every band has its own frequency, gain and width, with shelves at the ends, presets and a live response curve. Boosts turn the whole down to match, so loud music never clips.

Controls → Equalizer…  ⌥⌘E

Crossfeed for headphones

Each ear hears a little of the other channel, as it would from speakers, so hard-panned music doesn’t sit inside one ear. Light, Medium and Strong, after the bs2b design.

Controls → Crossfeed

Speed, with the pitch kept

Anywhere from 0.5× to 2× without the chipmunk effect, for practising along or catching every word. At 1× the audio passes through untouched.

⌘] faster  ⌘[ slower

Gentle on the ears

Playing and resuming fade in over a second, and turning the volume up glides there instead of jumping. Turning it down is instant. At full volume the sound is untouched.

Smooth on slow disks

Decoding runs up to three seconds ahead, so a USB disk waking up or retrying a bad spot doesn’t break up the sound.

Damaged files play on

A corrupt FLAC frame becomes a moment of silence instead of the end of the song, so you can still hear the rest while you find a better copy.

Library

Big libraries, many disks, no fuss

Point Mugig at your music folders, internal, USB or network, and it keeps up with them on its own.

  • Several music foldersUnplug a disk and its folder waits as “Not connected”; plug it back in and it is scanned again. Folders are watched for changes, and rescans are quick.
  • Playlists and smart playlistsAdd songs by hand, or write rules such as “Format is FLAC and Quality is Hi-Res” and let the list keep itself up to date.
  • CUE sheetsAn album ripped to one big file is listed song by song and plays back gapless, as on the CD. Sheets in Chinese, Japanese, Korean and Western Windows encodings are read too.
  • Leaves out what isn’t musicSounds inside apps and plug-ins, node_modules, hidden folders and the Trash stay out of your library.
  • Search and sortBy title, artist, album, time, year, format, size, quality or path. The line under the title totals what’s shown: tracks, artists, albums, listening time and size.
  • Select many songs at once⌘-click, ⇧-click or ⌘A, then play, queue, check or copy them together.
  • Show or hide columnsRight-click a column header, or use View → Columns.
  • Get Info, Show in Finder, Copy PathRight-click any song. Explorer on Windows, your file manager on Linux.
  • Move to TrashAsks first, and the file can always be put back. On a USB disk it goes to that disk’s own Trash.
  • Drag and dropDrop a folder on the window to add it, or audio files to play them.
  • Reads the file, not its nameThe format comes from the file’s own bytes, so misnamed files still play.
  • Light and darkFollows the system, or choose in View → Appearance.

Get Mugig

Build it in three steps

Mugig is built from source with Go, on macOS, Windows or Linux.

  1. Install Go and a C compiler

    Go 1.24 or later, and a C compiler, as the window and the audio output use C.

    macOS
    xcode-select --install
    Linux (Debian, Ubuntu)
    sudo apt install gcc libgl1-mesa-dev xorg-dev
    Windows
    A MinGW-w64 GCC, for example from MSYS2

  2. Get the source

    Clone the repository from GitHub.

    git clone https://github.com/yeungon/mugig.git
cd mugig

  3. Build and run

    Run it straight away, or package it as an app. The first build takes a few minutes.

    make run        # build and run
make package    # build the app (Mugig.app on macOS)
make install    # macOS: package and copy into /Applications

Builds for other systems

These collect their results in dist/. Windows and Linux builds use fyne-cross, which needs Docker running.

make mac            # Apple silicon and Intel
make windows        # also windows-arm64
make linux          # also linux-arm64
make all-platforms  # all three

Platform notes

Mugig is made and tested on macOS. On Windows and Linux it builds and should work, but has had far less use.

These are macOS only: switching the device’s sample rate, exclusive access, the system’s Now Playing controls, the native Open panel that lists all disks, and the macOS decoder used as a second opinion on damaged files.
